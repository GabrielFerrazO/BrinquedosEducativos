# 📸 Como Adicionar Fotos dos Produtos

## 🎯 Você precisa adicionar 4 fotos nesta pasta:

### ✅ Nomes EXATOS dos arquivos (use estes nomes):

1. **`patos.jpg`** - Foto dos Patos Educativos
2. **`bases-palitos.jpg`** - Foto das Bases com Palitos
3. **`quebra-cabecas.jpg`** - Foto dos Quebra-cabeças Dupla Face
4. **`circulos.jpg`** - Foto dos Kits Círculos Coloridos

---

## 📋 Instruções:

### 1. Prepare as fotos:
- **Formato**: JPG ou PNG (preferencialmente JPG)
- **Tamanho recomendado**: 800x600px ou 1200x900px
- **Peso máximo**: 500KB por foto (para carregar rápido)
- **Fundo**: Preferencialmente branco ou neutro
- **Enquadramento**: Produto centralizado e bem iluminado

### 2. Renomeie os arquivos:
- Salve com os nomes EXATOS acima (ex: `patos.jpg`)
- Use minúsculas
- Sem espaços ou caracteres especiais

### 3. Coloque nesta pasta:
```
/Users/juca/pearson-b2b-site/produtos/
```

### 4. Faça o upload para o GitHub:

```bash
cd /Users/juca/pearson-b2b-site
git add produtos/*.jpg
git commit -m "Adiciona fotos dos produtos"
git push
```

---

## ⚡ O Vercel vai atualizar automaticamente!

Assim que você fizer o `git push`, o Vercel detecta a mudança e faz o deploy em ~30 segundos.

---

## 🎨 Dica: Otimizar fotos antes de subir

Se as fotos estiverem muito pesadas, use:
- **Online**: https://tinypng.com/ (comprime sem perder qualidade)
- **Mac**: Aplicativo "Pré-visualização" → Exportar → Reduzir qualidade

---

**Quando adicionar as fotos, elas vão aparecer automaticamente nos cards dos produtos! 🎉**
